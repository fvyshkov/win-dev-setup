Windows dev setup

Рабочее окружение для Windows

Один файл ставит редактор, Python, Git и Claude Code, настраивает горячие клавиши — и можно писать код. Семь шагов, минут пятнадцать.

Что нужно заранее

  • Windows 10 (сборка 1809 и новее) или Windows 11
  • Права администратора на этом компьютере
  • Оплаченная подписка Anthropic — Claude Pro или Max. Без неё Claude Code не запустится.
1

Скачать два файла

Оба — в одну и ту же папку, например в «Загрузки». Они работают только вместе.

Скачать установщик .bat

И второй файл: setup-dev-environment.ps1

Браузер может сказать, что файл «может навредить компьютеру». Так он реагирует на любой .bat, независимо от содержимого — выбери «Сохранить» или «Всё равно скачать».

Не хочешь качать файлы? Открой PowerShell (Win → набери powershell → Enter) и вставь одну строку — она скачает и запустит всё сама:

irm __SITE_URL__/setup.ps1 -OutFile "$env:TEMP\setup.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\setup.ps1"

Тогда шаг 2 можно пропустить.

2

Запустить установщик

Двойной клик по setup-dev-environment.bat. Откроется чёрное окно и само расскажет, что делает на каждом шаге.

Windows пару раз попросит подтверждение:

  • Синее окно SmartScreen — нажми «Подробнее», затем «Выполнить в любом случае».
  • Окно «Разрешить приложению вносить изменения?» — «Да». Появится несколько раз, по разу на каждую программу.

Дальше ничего нажимать не нужно. Идёт 5–15 минут: качаются установщики. Долгая пауза на строке про дополнения к редактору — это нормально, там около 60 МБ.

В конце окно покажет список установленного с номерами версий.

3

Открыть новый терминал

Шаг обязательный, его легко пропустить. Установка прописала новые команды в систему, но окна, открытые до этого, о них не знают.

Закрой окно установщика. Открой новое: Win → набери terminal → Enter. Проверь, что всё на месте — вставь и нажми Enter:

code --version
python --version
git --version
claude --version

Каждая строка должна ответить номером версии. Если пишет «не является внутренней или внешней командой» — загляни в раздел «Если что-то пошло не так».

4

Создать папку проекта и открыть её

Проект — это просто папка с файлами. Создай её где удобно, например C:\work\test.

Открыть её в редакторе можно двумя способами:

  • Мышкой: Win → Visual Studio Code → Enter. В редакторе: меню File → Open Folder → выбери папку.
  • Из терминала: перейди в папку и открой её. Точка означает «текущая папка»:
cd C:\work\test
code .
5

Открыть терминал внутри редактора

Нажми Ctrl+Alt+T. Терминал откроется вкладкой рядом с файлами и сразу в папке проекта — никуда переходить не нужно.

Штатный Ctrl+` тоже работает: он открывает терминал панелью снизу. Дело вкуса.

6

Первый запуск и вход в аккаунт

В терминале набери две буквы и нажми Enter:

cc

При самом первом запуске Claude Code проведёт через короткую настройку:

  1. Спросит оформление — светлое или тёмное. Выбери стрелками ↑ ↓ и нажми Enter.
  2. Предложит способ входа. Выбери вариант с подпиской Claude (не вариант с API-ключом).
  3. Откроется браузер. Войди в аккаунт Anthropic — тот самый, на котором оплачена подписка.
  4. Браузер спросит разрешение — нажми кнопку подтверждения.
  5. Вернись в окно терминала. Вход подхватится сам, дальше спрашивать не будет.

Если браузер не открылся сам — в терминале будет ссылка, скопируй её и открой вручную.

7

Работать

Дальше просто пиши, что нужно сделать, обычными словами:

> сделай на python скрипт, который скачивает картинку по ссылке
> добавь обработку ошибок и напиши тесты
> запусти тесты и почини то, что упало

Выйти — Ctrl+C дважды или команда /exit.

Важно про команду cc. Это Claude Code с флагом --dangerously-skip-permissions: он меняет файлы и запускает команды, не спрашивая разрешения. Так быстрее, но в текущей папке он может сломать что угодно.

В чужих и важных папках запускай обычную команду claude — она делает то же самое, но спрашивает подтверждение на каждое действие.

Если что-то пошло не так

Команда cc не найдена

Почти всегда причина одна: открыт старый терминал. Закрой все окна терминала и открой заново. Не помогло — перезагрузи компьютер, тогда система точно подхватит новые команды.

В самом начале написало winget not found

Отсутствует встроенный установщик программ от Microsoft — бывает на старых сборках Windows 10. Поставь бесплатное приложение App Installer из Microsoft Store и запусти файл заново.

SmartScreen не даёт запустить файл

«Подробнее» → «Выполнить в любом случае». Это окно Windows показывает на любой скачанный из интернета .bat, что бы в нём ни было.

Батник открылся в Блокноте вместо запуска

Сбита привязка расширения .bat. Правый клик по файлу → «Открыть с помощью» → «Выбрать другое приложение» → Windows Command Processor.

Ругается, что не найден setup-dev-environment.ps1

Скачался только один файл из двух, либо они лежат в разных папках. Оба файла должны быть в одной папке.

Ctrl+Alt+T не открывает терминал

VS Code читает горячие клавиши при запуске. Если он был открыт во время установки — закрой его полностью и открой заново.

Установка замерла на строке про дополнения

Она не замерла, а качает: самое большое дополнение около 50 МБ. Обычно 1–3 минуты. Если стоит дольше пяти — нажми Ctrl+C, всё остальное уже установлено, а дополнения можно доставить внутри VS Code через панель Extensions.

Claude Code не пускает или просит оплату

Нужен активный платный план Anthropic — Claude Pro или Max. На бесплатном аккаунте Claude Code не работает.

Хочу, чтобы cc спрашивал разрешение

Открой папку с файлами, набери в адресной строке проводника cmd и нажми Enter, затем выполни:

setup-dev-environment.bat -Safe

После этого cc станет обычным claude, со спросом на каждое действие.

Скрипт открытый, его можно прочитать до запуска: setup-dev-environment.ps1 · setup-dev-environment.bat

Windows dev environment

One file installs the editor, Python, Git and Claude Code, sets up the hotkeys, and you can start writing code. Seven steps, about fifteen minutes.

Before you start

  • Windows 10 (build 1809 or newer) or Windows 11
  • Administrator rights on this machine
  • A paid Anthropic plan — Claude Pro or Max. Claude Code will not run without one.
1

Download two files

Put both into the same folder, for example Downloads. They only work together.

Download the installer .bat

And the second file: setup-dev-environment.ps1

Your browser may warn that the file "can harm your computer". It says that about every .bat regardless of content — choose Save or Keep anyway.

Prefer not to download files? Open PowerShell (Win → type powershell → Enter) and paste this single line — it fetches and runs everything for you:

irm __SITE_URL__/setup.ps1 -OutFile "$env:TEMP\setup.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\setup.ps1"

Then skip step 2.

2

Run the installer

Double-click setup-dev-environment.bat. A black window opens and narrates what it is doing at every step.

Windows will ask for confirmation a couple of times:

  • Blue SmartScreen window — click "More info", then "Run anyway".
  • "Do you want to allow this app to make changes?" — Yes. It shows up once per program.

Nothing else to click. It takes 5–15 minutes, mostly downloading. A long pause on the editor add-ons line is normal — that is about 60 MB.

At the end the window prints everything it installed, with version numbers.

3

Open a new terminal

Do not skip this one. The installer registered new commands system-wide, but windows opened before that do not know about them.

Close the installer window. Open a fresh one: Win → type terminal → Enter. Paste this and press Enter:

code --version
python --version
git --version
claude --version

Each line should answer with a version number. If you get "is not recognized as an internal or external command", see the troubleshooting section.

4

Create a project folder and open it

A project is just a folder with files. Create one wherever you like, for example C:\work\test.

Two ways to open it in the editor:

  • With the mouse: Win → Visual Studio Code → Enter. Then File → Open Folder → pick the folder.
  • From the terminal: go into the folder and open it. The dot means "the current folder":
cd C:\work\test
code .
5

Open a terminal inside the editor

Press Ctrl+Alt+T. The terminal opens as a tab next to your files, already inside the project folder — no navigating needed.

The stock Ctrl+` works too: it opens the terminal as a panel at the bottom. Whichever you prefer.

6

First launch and signing in

In the terminal type two letters and press Enter:

cc

On the very first launch Claude Code walks you through a short setup:

  1. It asks for a colour theme, light or dark. Pick with ↑ ↓ and press Enter.
  2. It offers sign-in options. Choose the one for a Claude subscription (not the API key option).
  3. A browser opens. Sign in to the Anthropic account that holds your paid plan.
  4. The browser asks you to authorise — click the confirm button.
  5. Go back to the terminal window. It picks the session up on its own and will not ask again.

If the browser does not open by itself, the terminal prints a link — copy it and open it manually.

7

Get to work

From here just describe what you want in plain words:

> write a python script that downloads an image from a url
> add error handling and write tests for it
> run the tests and fix whatever fails

To quit: Ctrl+C twice, or the /exit command.

About the cc command. It is Claude Code with --dangerously-skip-permissions: it edits files and runs commands without asking. That is faster, but it can break anything in the current folder.

In folders that matter, run plain claude instead — same thing, but it asks permission for every action.

Troubleshooting

cc is not recognised

Almost always the same cause: an old terminal window. Close every terminal and open a new one. Still nothing — reboot, and the system will definitely pick the new commands up.

It said winget not found at the very start

Microsoft's built-in package installer is missing — happens on older Windows 10 builds. Install the free App Installer from the Microsoft Store and run the file again.

SmartScreen blocks the file

"More info" → "Run anyway". Windows shows this for every .bat downloaded from the internet, whatever is inside it.

The .bat opened in Notepad instead of running

The .bat file association is broken. Right-click the file → "Open with" → "Choose another app" → Windows Command Processor.

It complains setup-dev-environment.ps1 is missing

Only one of the two files downloaded, or they ended up in different folders. Both must sit in the same folder.

Ctrl+Alt+T does nothing

VS Code reads hotkeys at startup. If it was open during the install, close it completely and reopen.

It froze on the add-ons line

Not frozen — downloading. The largest add-on is around 50 MB, so 1–3 minutes is normal. If it sits there for more than five, press Ctrl+C: everything else is already installed, and add-ons can be installed later from the Extensions panel in VS Code.

Claude Code refuses to start or asks for payment

An active paid Anthropic plan is required — Claude Pro or Max. Claude Code does not work on a free account.

I want cc to ask for permission

Open the folder with the files, type cmd in the Explorer address bar and press Enter, then run:

setup-dev-environment.bat -Safe

After that cc becomes plain claude, asking before every action.
