Windows dev setup

Рабочее окружение для Windows

Один файл ставит редактор, Python, Git и Claude Code и настраивает горячие клавиши. Дальше можно писать код.

Что нужно заранее

СистемаWindows 10 (сборка 1809+) или Windows 11
ПраваАдминистратор на этом компьютере
ПодпискаОплаченная Claude Pro или Max. Без неё Claude Code не запустится
ЧАСТЬ 1Установка

1Скачать и запустить

Скачать установщик .bat

Один файл. Скачался — двойной клик, дальше всё само.

Windows дважды спросит разрешение:

  • Синее окно SmartScreen — «Подробнее» → «Выполнить в любом случае». Оно появляется на любой скачанный .bat.
  • «Разрешить приложению вносить изменения?» — «Да», по разу на каждую программу.

Идёт 5–15 минут, окно рассказывает, что делает. Долгая пауза на строке про дополнения к редактору — это загрузка 60 МБ, не зависание.

Вариант для PowerShell, одной строкой

Win → набери powershell → Enter, вставь:

irm https://win-dev-setup.onrender.com/setup.ps1 -OutFile "$env:TEMP\s.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\s.ps1"

2Открыть новый терминал

Шаг обязательный. Установщик прописал новые команды, но окна, открытые до этого, о них не знают.

Закрой окно установщика. Win → набери terminal → Enter. Вставь и нажми Enter:

code --version
python --version
git --version
claude --version

Каждая строка должна ответить номером версии.

ЧАСТЬ 2Начать работать

3Открыть проект

Проект — это просто папка с файлами. Создай её где удобно, например C:\work\test, и открой:

cd C:\work\test
code .

Точка означает «текущая папка». Мышкой то же самое: Win → Visual Studio Code → меню File → Open Folder.

4Терминал внутри редактора

Ctrl+Alt+T — терминал откроется вкладкой рядом с файлами и сразу в папке проекта.

Штатный Ctrl+` тоже работает: терминал панелью снизу.

5Первый запуск и вход

В терминале набери две буквы и нажми Enter:

cc
  1. Спросит оформление, светлое или тёмное — выбери стрелками и нажми Enter.
  2. Предложит способ входа — выбери вариант с подпиской Claude, не с API-ключом.
  3. Откроется браузер. Войди в аккаунт Anthropic, на котором оплачена подписка.
  4. Подтверди доступ и вернись в терминал — дальше спрашивать не будет.

Браузер не открылся сам — в терминале будет ссылка, открой её вручную.

6Работать

Дальше просто пиши, что нужно, обычными словами:

> сделай на python скрипт, который скачивает картинку по ссылке
> добавь обработку ошибок и напиши тесты
> запусти тесты и почини то, что упало

Выйти — /exit или Ctrl+C дважды.

Про команду cc. Это Claude Code с флагом --dangerously-skip-permissions: он меняет файлы и запускает команды, не спрашивая. Быстро, но в текущей папке может сломать что угодно.

В важных папках запускай claude — то же самое, но с подтверждением каждого действия.

ЧАСТЬ 3Справка

Скриншоты в буфер

Ставить ничего не нужно, всё уже в Windows. Скриншот вставляется прямо в окно Claude Code — быстрее, чем описывать ошибку словами.

Win+Shift+SКусок экрана. Выдели прямоугольник мышкой — снимок в буфере
PrtScnВесь экран целиком (см. оговорку)
Alt+PrtScnТолько активное окно
Alt+VВставить снимок в Claude Code

Если PrtScn открывает «Ножницы» вместо копирования всего экрана — в Windows 11 так по умолчанию. Параметры → Специальные возможности → Клавиатура → выключить «Используйте кнопку PRINT SCREEN, чтобы открыть создание фрагмента экрана».

На ноутбуках PrtScn часто работает только с Fn.

Если что-то пошло не так

Команда cc не найдена

Почти всегда открыт старый терминал. Закрой все окна терминала и открой заново. Не помогло — перезагрузи компьютер.

Написало winget not found

Нет встроенного установщика Microsoft, бывает на старых сборках Windows 10. Поставь бесплатный App Installer из Microsoft Store и запусти файл заново.

SmartScreen не даёт запустить

«Подробнее» → «Выполнить в любом случае». Так Windows реагирует на любой скачанный .bat.

Файл открылся в Блокноте

Сбита привязка .bat. Правый клик → «Открыть с помощью» → «Выбрать другое приложение» → Windows Command Processor.

Ctrl+Alt+T не работает

VS Code читает горячие клавиши при запуске. Закрой его полностью и открой заново.

Claude Code просит оплату

Нужен активный платный план — Claude Pro или Max. На бесплатном аккаунте Claude Code не работает.

Хочу, чтобы cc спрашивал разрешение

В папке с файлом набери в адресной строке проводника cmd, Enter, затем:

dev-setup.bat -Safe

После этого cc станет обычным claude.

Скрипт открытый, можно прочитать до запуска: setup.ps1 · dev-setup.bat

Windows dev environment

One file installs the editor, Python, Git and Claude Code and sets up the hotkeys. Then you can write code.

Before you start

SystemWindows 10 (build 1809+) or Windows 11
RightsAdministrator on this machine
PlanA paid Claude Pro or Max plan. Claude Code will not run without one
PART 1Install

1Download and run

Download the installer .bat

One file. Once downloaded, double-click it and it does the rest.

Windows will ask twice:

  • Blue SmartScreen window — "More info" → "Run anyway". It shows up for every downloaded .bat.
  • "Allow this app to make changes?" — Yes, once per program.

Takes 5–15 minutes and narrates what it is doing. A long pause on the editor add-ons line is a 60 MB download, not a freeze.

PowerShell one-liner instead

Win → type powershell → Enter, then paste:

irm https://win-dev-setup.onrender.com/setup.ps1 -OutFile "$env:TEMP\s.ps1"; powershell -ExecutionPolicy Bypass -File "$env:TEMP\s.ps1"

2Open a new terminal

Do not skip this. The installer registered new commands, but windows opened before that do not know about them.

Close the installer window. Win → type terminal → Enter. Paste this and press Enter:

code --version
python --version
git --version
claude --version

Each line should answer with a version number.

PART 2Start working

3Open a project

A project is just a folder with files. Create one wherever you like, say C:\work\test, and open it:

cd C:\work\test
code .

The dot means "the current folder". Same thing with the mouse: Win → Visual Studio Code → File → Open Folder.

4A terminal inside the editor

Ctrl+Alt+T — the terminal opens as a tab next to your files, already in the project folder.

The stock Ctrl+` works too: terminal as a bottom panel.

5First launch and sign-in

In the terminal type two letters and press Enter:

cc
  1. It asks for a light or dark theme — pick with the arrow keys and press Enter.
  2. It offers sign-in options — choose the Claude subscription one, not the API key.
  3. A browser opens. Sign in to the Anthropic account that holds your paid plan.
  4. Authorise, then go back to the terminal — it will not ask again.

If the browser does not open by itself, the terminal prints a link — open it manually.

6Get to work

From here just say what you want in plain words:

> write a python script that downloads an image from a url
> add error handling and write tests for it
> run the tests and fix whatever fails

To quit: /exit or Ctrl+C twice.

About cc. It is Claude Code with --dangerously-skip-permissions: it edits files and runs commands without asking. Fast, but it can break anything in the current folder.

In folders that matter, run claude instead — same thing, but it asks before every action.

PART 3Reference

Screenshots to the clipboard

Nothing to install, Windows already does this. A screenshot pastes straight into the Claude Code window — faster than describing an error in words.

Win+Shift+SA region. Drag a rectangle — the shot is on the clipboard
PrtScnThe whole screen (see the caveat)
Alt+PrtScnThe active window only
Alt+VPaste the shot into Claude Code

If PrtScn opens the Snipping Tool instead of copying the whole screen — that is the Windows 11 default. Settings → Accessibility → Keyboard → turn off "Use the Print screen key to open Snipping Tool".

On laptops PrtScn often needs Fn held with it.

Troubleshooting

cc is not recognised

Almost always an old terminal window. Close every terminal and open a new one. Still nothing — reboot.

It said winget not found

Microsoft's built-in installer is missing, which happens on older Windows 10 builds. Install the free App Installer from the Microsoft Store and run the file again.

SmartScreen blocks it

"More info" → "Run anyway". Windows does this for every downloaded .bat.

The file opened in Notepad

The .bat association is broken. Right-click → "Open with" → "Choose another app" → Windows Command Processor.

Ctrl+Alt+T does nothing

VS Code reads hotkeys at startup. Close it completely and reopen.

Claude Code asks for payment

An active paid plan is required — Claude Pro or Max. It does not work on a free account.

I want cc to ask permission

In the folder with the file type cmd in the Explorer address bar, Enter, then run:

dev-setup.bat -Safe

After that cc becomes plain claude.

The script is open, read it before running: setup.ps1 · dev-setup.bat
